# Git Foundations — Code lab

Release day goes sideways: stash your work, revert a bad push, branch, reset a local mistake, pull a teammate's change, resolve a merge conflict, merge and push.

- **Edit:** one bash script per step in `src/` (`step4_stash.sh` ... `step10_merge_and_push.sh`). Each script has `TODO` comments for its step.
- **Run the tests:** **Run Tests** in Exa Studio, or `pip install -r requirements.txt` then `python -m pytest -q`. All 7 visible tests fail at first; every message starts with `Step N:`.
- **Needs Linux (or WSL) with bash and git.** The tests run your scripts on a fresh temp copy of the scenario. `python -m test.sandbox` makes a practice copy to try commands in first.
- **Done** when every visible test passes. **Submit** also runs held-out tests you can't see.

Full task steps and hints: [`.evolv/instructions.md`](.evolv/instructions.md)
